# Glossary

This glossary defines common terms used in contract interaction discussions.

## External Call
A function call made from one contract to a different contract address.

## Internal Call
A function call made within the same contract.

## Execution Context
The environment in which contract code runs, including state, sender information, and transaction data.

## State
Persistent data stored by a smart contract on the blockchain.

## Event
A log entry emitted by a contract that allows external systems to observe activity.
